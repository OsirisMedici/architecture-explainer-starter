# Presentation design

The reference is `presentation-concept.png`, generated for this starter from the established Hairline direction in the project conversation. It defines one white editorial presentation screen, a narrow topic rail, serif headings, simple controls, a single large line drawing and a short explanatory caption.

Tokens: pure white paper, charcoal `#282c30`, pale gray `#dedfe0` rules, muted gray `#797e83` labels. Headings and presentation controls use Georgia; metadata uses the system sans family. Controls have a 3px radius and restrained state changes. The drawing uses thin monochrome silhouettes and one stronger line for airflow.

The initial scene is Vent open. Main copy, topic order, header actions and caption follow the concept. Intentional functional extensions are a sources disclosure, explicit assumption notes, a mobile topic grid, keyboard presentation controls, optional project photographs and portable export.

The reference illustration is not a supplied project drawing. The runtime SVG is a schematic parametrised model drawn with Hairline's actual projection, solid and spring functions. It retains the two-storey courtyard, open section and ventilation gesture; planting and architectural detail from the generated reference are not claims about a real building.

The starter has no photographs or user data. The generated reference is design documentation, not an app background or a substitute for working controls.
